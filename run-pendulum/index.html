走り：脚を「股関節の振り子」で動かす試作（221j）

2026-10-02。「動画は股関節を支点にした振り子に近い。今の足はロボットのよう」というご指摘への試作です。処理はすべて Windows 機で行っています。

分かったこと

SSOT は、股関節から足先までの長さがほぼ一定のまま（ばらつき約 7%）、脚が振り子のように振れていました。足先の向きも脚の振りと一緒に回っています。今までの版（221f・221i）は、足先を「前後・高さ」で直接動かしていたため、脚がピストンのように伸び縮みしていました（ばらつき 26〜31%、すれ違い時は長さが約 1/3）。

（SSOT の解析。青・橙の線＝推定した支点から足先、赤＝足の向き）

221j でしたこと

  • 脚を「股関節の角度・脚の長さ・足首の角度」で動かす方式に変更（骨リグの標準的な動かし方と同じ）。
  • すれ違いでは足を床すれすれに通す（ご判断どおり）。
  • 結果：脚の長さのばらつき 26% → 17%、振りの滑らかさ 89% → 98%、途中で止まる箇所 0、足先の向きと脚の振りの連動もほぼ完全。

下の図は体を基準にした足先の通り道（黒丸＝股関節）。221j は振り出し側が股関節を中心にした弧になりました。ただし接地中は足が床に沿って平らに動くため、その間は脚の長さが変わります。

正直な評価と残っている点

  • 数値上は振り子に近づきましたが、見た目の違いは 221i から小さいと私は見ています。
  • すれ違いの瞬間、SSOT は後ろの足が前の足の真後ろに隠れますが、221j は 2 つの足が上下に重なって見えます。
  • 後ろ足が 3D 上で尻尾に少しめり込むコマがあります（12 コマ）。腕の 2 項目は以前からの既知の項目です。
  • Mozu は脚が短く股関節が低いため、SSOT のような長い脚の振り子をそのまま再現するには、体型か動きのどこかを変える必要がありそうです。
