肩の付け根を前に出す（肩帯）試作

腕が顔に埋まって小さく見える根本原因は、腕の付け根が大きな頭の張り出しの真下に固定されていること（Fable と GPT-6 の独立判断が一致）。付け根を胴の表面に沿って前へスライドさせる肩帯を足し、腕の曲げは E（中くらいの柔らかさ）のまま。手は頬に「触れる」だけ（埋めない）。各図の列：左端＝元動画、以降＝付け根 固定 / 25° / 40°+持ち上げ × 腕の伸び 1.0 / 1.2 の組み合わせ（並びは README 参照、右端が 40° + 伸び 1.2）。オフラインの粘土描画（上半身を拡大）。

洗顔（頬に当てる f32）

自己レビュー：右端（40° + 伸び 1.2）が最良。正面で手のひらが口の高さで頬に乗り、その下に前腕が縦に立つ（元動画の正面に近い）。斜めでも腕全体が見える U 字。付け根の継ぎ目はどの視点でも隠れている。固定の付け根では頬に届かない（左の列）。横から見ると「あごのすぐ下・胸の上から出る腕」とも読める境界線上。

歯磨き（口元に当てる f54）

自己レビュー：頭は水平〜少しあご上げ、ブラシ側へ少し向けたので「うつむき」は解消。拳の下に前腕が縦に立ち、ブラシは横持ちで口元へ。届くのは伸び 1.2 + 肩帯ありだけ。残課題：上腕が内側へ曲がって首の横に入り、正面で付け根の継ぎ目が見える（胸から生えた腕に見える）。肘を拳の外側・十分下に置く条件は未達。

判断をお願いしたいこと

  1. 肩が前にスライドする動き（洗顔では継ぎ目は見えない）を受け入れるか
  2. 手は頬に「触れるだけ」でよいか（以前は頬に沈んでいた）
  3. 頬が手で少しへこむ変形を入れるか
  4. 歯磨きの残課題：肘を外へ出すには「伸び 1.4」か「腕の長さの見直し（体型変更）」が必要になりそう。どちらを試すか
