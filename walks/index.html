置き換えた歩き

walk 1.0.0（211）は、今回の 1.1.0 に置き換えました。腕の振りが大きく、足首がカクカクすると指摘のあった版です。ファイルは消さずに残してあり、必要ならいつでも戻せます。

使い方

  • 現在の版は python3 scripts/mozu_asset.py resolve --motion walk（sneak / run も同様）で取得できます。
  • Blender では append_scene(motion="walk") で読み込むと、Mode とフレーム範囲まで自動で設定されます。
  • ジャンプ（jump 2.0.0）は変更していません。
  • 歩き・走りの切り替えはモードの選択式で、切り替え時のつなぎの動きはまだありません。
