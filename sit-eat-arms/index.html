座ったときの腕：どう直すかの判断ページ

2026-10-03。おすわり＋おにぎり（SE212）の r12。座ると腕が太ももの後ろに隠れて見切れる件。

1. いまの問題

腕を赤・青に塗り分けて撮影（左：通常、右：腕だけ）。正面では腕が腰・太ももの後ろに入っています。

見る方向腕が見えている割合先端（手）が見えている割合
正面約 31%約 6%
斜め（手前の腕）86%97%
横（手前の腕）94%100%

元動画（座り終わり）：腕は体の前側に沿って下がり、手は足の少し上でお腹の下に乗っていて全部見えています。

2. 原因

  • 座る動きは横からの元動画だけで合わせていて、腕を前に出す量・開き・上げ具合は合わせていませんでした（前回の足と同じ原因）。
  • さらに根本には、腕の肩の付け根が体の中ほどの深さに固定されていることがあります。座ると太ももが前と上に膨らむので、手の先はすでに太ももと体に少しめり込んでいます（体 -0.08、太もも -0.06）。
  • 今ある腕の動き（前後・上げ・曲げ・長さ）だけで元動画の手の位置に合わせると、手はお腹の中へ入ってしまいます（下の中段・不採用）。約 3万6千通り試しても、めり込まない組み合わせはありませんでした。

上段 r12／中段 今の動きだけで手の位置を合わせた試作（腕が体に埋まって見えない＝不採用）／下段 元動画

3. 提案：座るときだけ肩の付け根を前へ移す（見た目のイメージ）

腕を前に平行移動しただけのイメージです（実際の作り直しでは、肩を体の表面に沿って移し、手が太ももの上に乗るよう腕の角度も合わせます）。

前への移動量手先と体のすき間手先と太もものすき間
0（r12）-0.083（めり込み）-0.055（めり込み）
0.15-0.063-0.108
0.25-0.032-0.133
0.35+0.010（離れる）-0.156

平行移動だけだと、体からは離れても今度は前に盛り上がった太ももに手が入ります。本番では手を太ももの上に乗せる角度も同時に解き、めり込みゼロと「手が8割以上見える」をチェックで確かめます。

4. 選択肢

A. 座るときだけ肩の付け根を前へ移す動きをリグに追加おすすめ
  • 手がお腹の前・太ももの上に来て、元動画のように正面・斜め・横で見える。
  • 横から見ると手が少し前に出る（元動画の横も手は体の中心より前なので近づく）。
  • 座っていない間（立ち・歩き・走り）は今のまま。食事の動きもそのまま。
B. 今のまま（r12）
  • 正面で手が隠れ、手先が太ももに少しめり込んだまま。
C. 肘のある新しい腕のリグ（別セッションで開発中）を待って、それで座りを作り直す
  • 肘で曲げて手を太ももに置けるので、根本的にはこちらが本命になり得る。
  • ただし完成時期は未定で、他の動き（食事など）も作り直しになる。

5. 決めていただきたいこと

A / B / C のどれにするか、チャットで返信してください。A の場合、前への移動量の目安（イメージ上は 0.25〜0.35 あたり）にご希望があれば添えてください。
